# 75 个原题号的适配范围

先区分“题号有可执行数值入口”和“原题要求全部有可靠数据与评价”。原有 55 个数值入口的模型、预测、标签身份和主要指标已逐项复核，但它们共用 13 个真实拟合模型，部分题目只得到同一组预测。费用、维修调度、法规合规、物理风险、多模态比较等缺少相应数据的要求仍不可评分。它们也不是本次新跑的 55 次大模型实验。

其余 20 个题号如下；`scenario list --task <题号>` 可查看完整原题、实际来源及限制。这里“可运行”指可对真实实验数据或明确标注的 NASA 仿真数据运行数值子任务；分数是否有研究价值仍需核对任务、数据划分和表现。

| 题号 | 实际数值来源 | 来源关系 | 可运行部分及未覆盖内容 |
|---|---|---|---|
| `pdm_fault_010` | UoC | 原题相关来源 | 九种输入小齿轮状态分类；不能识别其他齿轮部件，物理采集独立性未知 |
| `pdm_safety_007` | CWRU | 原题相关来源 | 轴承状态分类；无安全风险或法规合规真值 |
| `pdm_rul_005`、`pdm_rul_011`、`pdm_safety_010` | IMS | 原题相关来源 | 预测距录波终点的采集次数；不等于物理失效时刻，无异常或安全标签，测试只有四个轴承通道 |
| `pdm_rul_008`、`pdm_rul_014` | Paderborn LDM | 同机构的不同数据 | 作者派生特征预测记录终点；不是原诊断 KAt 数据，不包含四传感器消融；测试只有五只轴承 |
| `pdm_rul_002` | FEMTO | 替代 CWRU | 轴承剩余时间预测；不是 CWRU 失效时间或退化曲线 |
| `pdm_rul_006`、`pdm_rul_012` | XJTU-SY | 替代 HUST | 预测名义采集终点；不是 HUST 设备，测试仅三只轴承 |
| `pdm_rul_007`、`pdm_rul_013` | FEMTO | 替代 MFPT | 轴承剩余时间预测；不是 MFPT，未完成时域与频域的受控对照 |
| `pdm_rul_009`、`pdm_rul_015` | Paderborn LDM | 替代 Mendeley | 记录终点代理，不代表 Mendeley 变转速实验或其轴承小时数；Mendeley Ferrara 原始寿命数据有公开来源，但本入口未接入 |
| `pdm_rul_010` | NASA C-MAPSS FD002 仿真 | 替代 Azure | 发动机剩余循环预测；不是 Azure 机器、大规模部署测试或峰值内存评估 |
| `pdm_cost_benefit_005` | NASA C-MAPSS FD001 仿真 | 替代 Azure | 发动机剩余循环预测；成本、批量折扣和最优排程未知 |
| `pdm_fault_005`、`pdm_safety_005` | 尚无合格入口 | 不可用 | PlanetaryPdM 已公开的裂纹阶段不能自动当成太阳轮、行星轮、齿圈部件标签；安全和合规真值未具备 |
| `engine_health_combined_029`、`engine_health_combined_030` | 无对应真实来源 | 不可用 | 两道题是合成的 10 周期信号模板，没有匹配的真实记录和真值；不能虚构数据称为真实实验 |

7 个相关来源部分适配包含 2 个明确使用不同 Paderborn 数据集的题号；9 个完全替代来源的入口须显式选择 `--include-substitutions` 或逐题 `--task`。4 个不可用题号不会出现在批量运行中，显式选择会报错。每个运行结果记录 `source_relation` 与 `complete_original_task_claimed: false`，共享模型不构成独立实验。

具体数据来源、大小、安装、实验限制与验证结果分别见 [数据说明](DATASETS.md) 和 [验证记录](VALIDATION.md)。
