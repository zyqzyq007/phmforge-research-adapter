一轮训练和 smoke 只验证链路接通，不是性能或 Agent 能力比较。C-MAPSS 是 NASA 官方仿真数据，MFPT 是台架实测。跨机器复制历史制品、用户机器的网络和内核配置以及其他未执行的历史命令仍需在目标环境中验证；GitHub 单独克隆只支持从公开数据准备两个数值子任务。

本记录是 2026-10-27 的工程验证，不是 PHMForge 官方成绩，也不是新的独立科学结论。测试环境为 Linux x86-64、Python 3.12、CPU 和 bubblewrap。

- 在新的虚拟环境中，从软件源安装 `requirements.txt`，以 editable 安装及构建 wheel；wheel 安装后可运行命令行、MCP 服务和隔离评分。主要依赖版本见 `requirements.txt`。
- MFPT 从固定 MathWorks 来源下载并校验 20 个 `.mat` 文件；真实 MLP 训练 1 轮发生 16 次非零梯度更新，最终冷推理覆盖 684 个留出窗口。采集记录之间按 11／3／6 划分。
- NASA C-MAPSS FD001 从项目代码指定的镜像下载并校验压缩包和原始成员；真实 MLP 训练 1 轮发生 12 次非零梯度更新，最终冷推理覆盖 100 台仿真发动机。训练／开发／测试为 80／20／100 台。
- 随机测试身份加固后，逐项核对 MFPT 特征、C-MAPSS 传感器值及原始真值均未改变；对相同冻结程序的前后评分一致。独立进程检查确认训练／开发资料、隐藏标签、宿主机凭据和网络未挂载。
- 两个数据集的 MCP 服务各发现 22 个工具，训练／开发数据及开发标签可按合同读取；最终测试数据和标签不可由服务读取，不具备物理依据的健康评估返回 unavailable。仓库内六项软件合同和隔离检查通过。
- 一次自由开发的 Codex CLI 0.164.0／`deepseek-flash` 会话发起真实模型调用和代码执行；其长时间模型搜索两次被控制器中断，整个会话在 1200 秒内未正常提交。该会话保留为失败的工程尝试，不能当作有效 Agent 结果。
- 一次单独的 `--smoke` 会话按约定保留真实拟合的初始程序，8 次模型请求均得到 HTTP 200，实际返回模型为 `deepseek-flash`；MCP 成功读取开发标签，提交程序对 684 个隐藏窗口完成隔离评分。这是接通验证，不能作为自由开发能力或模型改进的证据。

这些测试使用已经公开且此前被研究人员查看过的数据。随机身份可以降低按原始编号直接查标签的风险，但无法防止识别或记忆公开数据。项目尚未实现全部 75 个原题或原题中的维护、监管和安全评价。
