# 实际科研主脚本快照

本目录逐字节保存实验项目中的 Python 主脚本，`SOURCE_MANIFEST.json` 给出来源键和 SHA-256。包含数据准备、数值工具、Agent 驱动、原生程序注册、评分、分析与归档入口。各历史批次真正使用的冻结版本另外保存在环境制品的 `runs/<批次>/code` 等目录中。

原脚本保留当时的绝对路径、协议和失败分支，便于审计。运行历史任务优先使用已迁移的 `phmforge-bench environment` 入口；直接复用这些脚本时，需要按对应协议配置路径和权限。历史材料中的模拟实现审计、失败实验和合成对照没有因此获得真实 PHM 成绩资格。

此快照没有加入安装包的 Python 搜索路径，不会替换已核验的数值后端，也不包含 API 凭据。
